# Game Servers

The lab hosts dedicated Palworld and Valheim server VMs on the server VLAN.

Portfolio documentation will focus on:

- VM and storage design
- Service lifecycle and restart behavior
- Firewall and NAT requirements
- Backup of configuration and save data
- Zabbix availability and resource monitoring
- Upgrade and rollback procedures

Player information, passwords, save archives, and public connection details are excluded.
