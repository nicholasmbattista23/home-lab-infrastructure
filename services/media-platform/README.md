# Media Platform

The media platform separates storage/application services from ingest and automation services.

## media-01

- Plex
- Immich
- Samba
- Local media storage

## media-ingest-01

- Docker
- qBittorrent
- Sonarr
- Radarr
- Prowlarr
- Byparr
- Privoxy

Future examples may include sanitized Compose files, health checks, storage-mount conventions, and backup procedures. They will exclude credentials, API keys, indexer details, VPN configuration, media, and personal photo data.
